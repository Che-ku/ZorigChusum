# Zorig Chusum

A SwiftUI iOS app introducing Bhutan's thirteen traditional arts and crafts.

## Features

- Browse all thirteen crafts in a SwiftUI `List`
- Search by Dzongkha or English name
- Open a detail screen using `NavigationStack` and `NavigationLink`
- View a large symbolic illustration and a concise description
- Mark a craft as visited during the current app session
- Styled rows, cards, colours, spacing, dividers, and rounded corners

## Requirements

- Xcode 15 or newer
- iOS 17 or newer

## Run

1. Clone this repository.
2. Open `ZorigChusum.xcodeproj` in Xcode.
3. Select an iPhone Simulator.
4. Press **Run** (`Command-R`).

No external packages, database, or network connection are required.
